项目概览

银杏AI 是一个完全自主设计的多模态AI助手平台，基于智谱 GLM-4-Flash 大语言模型驱动， 集成 Agnes 多模态引擎实现视觉识别、图像生成与视频创作。全栈 Python/Flask 实现， 前后端一体化，开箱即用。

智谱GLM-4-Flash驱动，128K上下文，支持深度思考与多轮对话

👁️

Agnes-2.0-Flash多模态模型，支持图片识别、描述、问答

🎨

图像生成引擎

Agnes-Image-2.1-Flash驱动，文生图与图生图双模式

🎬

视频生成引擎

Agnes-Video-V2.0驱动，文生视频与图生视频创作能力

🔍

智能联网搜索

DuckDuckGo集成，AI自动判断是否需要联网搜索最新信息

🔧

系统架构

银杏AI 采用分层微服务架构设计，从底层AI模型API到上层Web界面清晰分离。 Flask后端通过RESTful API与前端通信，多引擎调度器根据用户意图路由到对应处理模块。

对话流程

用户输入接收

Flask后端接收前端发送的文本消息，包含会话ID和深度思考标记

意图识别与路由

GinkgoAI引擎通过正则匹配识别工具命令，自动路由到对应处理器

智能搜索判断

对于非工具类问题，AI自动判断是否需要联网搜索最新信息

GLM-4-Flash 调用

构造包含系统提示词和对话历史的Messages，调用智谱API

响应解析与返回

解析AI响应，提取思考过程和最终答案，返回前端展示

系统提示词设计

银杏AI 使用精心设计的系统提示词（System Prompt）定义AI的身份、能力边界和回答规范。 128K的超长上下文窗口确保复杂对话也能保持连贯性。

提示词模块功能说明
身份定义AI身份声明当被问及身份时，第一句话回答"我是银杏AI，基于智谱GLM-4-Flash模型"
能力声明功能列表明确列出视觉识别、图像生成、视频生成等所有能力
回答纪律行为约束遇到视频生成指令时，必须直接调用工具而非建议其他平台
深度思考格式输出格式深度模式下必须包含"思考："和"回答："两部分
技术参数模型参数上下文128K tokens，单次生成最大4000 tokens

视觉识别能力

银杏AI 集成 Agnes-2.0-Flash 多模态视觉模型， 支持用户上传图片后进行智能识别、描述和问答，实现"看图说话"能力。

视觉处理流程

图片上传

用户通过前端界面上传图片，前端将图片转为Base64编码

图片存储

Flask后端接收Base64数据，解码后保存到static/uploads/目录

Agnes API 调用

将图片Base64和用户文本发送到Agnes视觉模型API

智能分析返回

视觉模型返回图片分析结果，前端以Markdown格式渲染展示

多模态融合

视觉识别与文本对话无缝融合——用户可以在发送图片的同时附带文字提问， AI会综合图片内容和文字问题给出精准回答。

图像生成引擎

银杏AI 集成 Agnes-Image-2.1-Flash 图像生成模型， 支持文生图（Text-to-Image）和图生图（Image-to-Image）两种创作模式。

✏️

文生图模式

输入文字描述即可生成高质量图片，支持自定义尺寸

🖼️

图生图模式

上传参考图片+文字描述，AI基于参考图进行二次创作

图像生成参数

参数类型默认值说明
model字符串agnes-image-2.1-flash图像生成模型
prompt字符串—图像描述文本
size字符串1024x768输出图片尺寸
image数组—图生图模式的参考图片
response_format字符串url返回格式（url/b64_json）

视频生成引擎

银杏AI 集成 Agnes-Video-V2.0 视频生成模型， 支持文生视频与图生视频，采用异步任务模式，生成完成后自动通知用户。

📹

文生视频

输入文字描述，AI自动生成1-3分钟的短视频

🎞️

图生视频

上传一张图片作为起始帧，AI将其动画化为视频

⚙️

异步任务管理

视频生成采用异步模式，前端自动轮询状态，完成后推送结果

🎛️

参数可调

支持帧数、帧率、分辨率、种子值等参数自定义

视频生成参数

参数类型默认值说明
model字符串agnes-video-v2.0视频生成模型
prompt字符串—视频描述文本
num_frames整数121生成帧数（约5秒@24fps）
frame_rate整数24帧率（fps）
width整数1152视频宽度（像素）
height整数768视频高度（像素）
image字符串—图生视频的起始帧URL
seed整数随机随机种子（可复现生成）

视频生成流程

任务创建

用户提交视频描述，后端向Agnes API创建异步生成任务

状态轮询

前端每3秒自动查询任务状态，展示生成进度百分比

生成完成

任务完成后返回视频URL，前端自动播放并保存到会话记录

本地环境限制

图生视频模式需要公网可访问的图片地址。在本地开发环境（127.0.0.1/localhost）中， 请改用文生视频模式，或使用内网穿透工具（如 ngrok）将本地服务暴露到公网。

工具调用架构

每个工具以Python方法实现，注册到self.tools字典中。 意图识别模块通过正则表达式匹配用户输入，自动路由到对应工具函数， 返回结果后由前端以Markdown格式渲染。 

# 工具注册示例
self.tools = {
    "time": self.get_time,
    "date": self.get_date,
    "calc": self.calculate,
    "weather": self.get_weather,
    "画图": self.generate_image_tool,
    "生成视频": self.generate_video_tool,
    # ... 更多工具
}

# 意图识别示例
weather_patterns = [
    (r'^天气\\s+(.+)$', 'weather'),
    (r'^(.+?)天气怎么样$', 'weather'),
]
for pattern, intent in weather_patterns:
    match = re.match(pattern, lower)
    if match:
        return intent, match.group(1)

部署指南

银杏AI 是标准的 Python Flask 应用，使用 pip + python 即可部署，无需编译。

环境要求

依赖说明
Python 3.8+运行环境

flask-corsCORS跨域支持
requestsHTTP客户端，用于API调用
智谱 API KeyGLM-4-Flash 模型访问
Agnes API Key视觉/图像/视频模型访问

快速启动

# 1. 克隆仓库
git clone https://github.com/kksjkk/GinkgoAI.git
cd GinkgoAI

# 2. 安装依赖
pip install flask flask-cors requests

# 3. 在 config.py 中配置 API 密钥
ZHIPU_API_KEY = "your-zhipu-key"
AGNES_API_KEY = "your-agnes-key"
AGNES_BASE_URL = "https://apihub.agnes-ai.cn"

# 4. 运行应用
python app.py
# 浏览器自动打开 http://127.0.0.1:5000
