项目概览

WeaveOS 是一个完全自主设计的 64 位 x86 操作系统，采用 Multiboot2 + GRUB 引导，支持 BIOS/UEFI 双模式启动。内核运行在 Ring 0，桌面和应用通过 INT 0x80 系统调用请求服务。

安全机制

多层安全防护，从内核级到用户级全方位保障。共 15 个安全模块，3,858 行安全代码。

🎲

ASLR

地址空间布局随机化。栈(28位)/堆(24位)/mmap(28位)/代码段(24位)随机化。

🔒

Stack Protector

栈金丝雀保护。随机生成金丝雀值，函数返回前校验。

🛡️

SMEP/SMAP

防止内核态执行/访问用户态内存。CPUID 检测，CR4 位操控。

🔐

CFI

控制流完整性。Shadow Stack 验证返回地址，每进程状态。

🔑

Secure Boot

UEFI 安全启动。签名验证、可信密钥库、哈希计算。

🧱

防火墙

内核级包过滤。规则匹配、默认策略、统计追踪。

📝

审计日志

环形缓冲区审计。启动/登录/失败/文件访问/权限拒绝。

👤

认证与权限

认证、密码散列、Set-UID、权限检查、能力模型。

构建系统

Multiboot2 + GRUB 引导，BIOS/UEFI 双模式支持。构建过程：编译所有 .c/.S → 链接 kernel64.elf → grub-mkrescue 生成 weaveos64.iso。

启动流程

BIOS/UEFI 引导

系统上电，BIOS/UEFI 初始化硬件，从 ISO 或磁盘加载 GRUB。

GRUB 加载内核

读取 grub.cfg，加载 kernel64.elf 到内存，切换到保护模式。

汇编入口

bootasm.S 设置栈，初始化分页，进入 64 位长模式。

内核初始化

初始化内存管理、中断、PIT、键盘鼠标、VGA、文件系统。

WAFS 挂载

挂载根文件系统，创建默认目录结构。

安装检查

installer_check_installed() 判断已安装则进入桌面，否则运行安装器。

桌面启动

初始化桌面组件，进入桌面主循环。

构建命令

./run.sh          默认 BIOS 启动
./run.sh bios     BIOS 模式
./run.sh uefi     UEFI 模式
./run.sh nogui    无图形模式
./run.sh virtio   VirtIO 磁盘
