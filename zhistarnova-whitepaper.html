项目概览

ZhiStar Nova 是一个完全自主设计的现代桌面浏览器项目，基于 WebKit2GTK 4.1 深度定制， 从 UI 渲染到交互逻辑全部用纯 C11 实现，零 C++ 依赖。它不仅是一个浏览器， 更是对 WebKit 浏览器引擎的深度实践与定制。

🌐

Nova-Engine 渲染引擎

基于 WebKit2GTK 4.1 深度定制，支持硬件加速与软件渲染双模式

⚡

Nova-JS 脚本引擎

WebKit JavaScriptCore 完整 JavaScript 执行环境

🎨

Nova-Render 图形引擎

GTK3 + Cairo 自绘 UI，支持动态 CSS 主题切换

🛡️

ZTP 隐私引擎

内建广告拦截、Do Not Track、Cookie 策略、追踪保护

🔧

Pure C11 Core

纯 C11 标准，零 C++ 依赖，编译即运行

📥

专业下载管理

自动检测 60+ 文件格式，速度估算，并发控制，下载历史

系统架构

ZhiStar Nova 采用经典的分层架构设计，从底层 WebKit 依赖到上层浏览界面清晰分离。 浏览器核心运行在主进程中，通过 WebKit2GTK 的多进程架构实现标签页隔离。

隐私与安全

ZhiStar Nova 内建 ZTP 隐私引擎，提供 CSS 级广告拦截、 追踪保护、Cookie 策略、Do Not Track 等多层隐私防护。

CSS 级广告拦截器

通过 webkit_web_context_set_stylesheet() 注入自定义 CSS 到所有页面， 使用 WebKitUserStyleSheet 实现无延迟的页面级广告隐藏。

拦截类别CSS 选择器说明
Google 广告.adsbygoogle, .ads, [id*="google_ads]Google AdSense 广告单元
通用广告容器[class*="ad-container"], [id*="ad-"]常见广告容器类名匹配
广告 iframeiframe[src*="ads"], iframe[src*="doubleclick"]广告 iframe 嵌入
弹窗覆盖层.modal-ad, .popup-overlay, .overlay-ad弹窗式广告覆盖
原生广告[class*="sponsored"], [class*="promoted"]伪装为内容的原生广告
百度广告#content_right, .ec_tuiguang_link百度搜索广告与推广
淘宝/电商.shoplink, .J-hover, [data-click]电商平台推广链接

自定义拦截规则

用户可在 ~/.config/zhistar/adblock.txt 中添加自定义 CSS 选择器， 格式为每行一个 CSS 选择器，支持 # 注释和 ! 例外规则。

自定义规则示例

# 这是注释
.my-custom-ad-class
div[data-ad-type="banner"]
! .important-content # 例外：不拦截此类

文件上传

ZhiStar Nova 实现了完整的文件上传支持，包括原生文件选择对话框拦截和 拖拽上传功能。

📂

文件选择器

拦截 run-file-chooser 信号，使用 GTK 原生文件对话框，支持 MIME 类型过滤

🖐️

拖拽上传

在 C 层读取文件内容，base64 编码，创建 JS File 对象，触发合成 DropEvent

拖拽上传实现流程

GTK Drop 事件接收

接收 GTK drag-data-received 信号，获取 URIS 列表

文件内容读取

在 C 层通过 GFile 读取文件内容，获取 MIME 类型和文件大小

Base64 编码

将文件二进制内容编码为 Base64 字符串，用于跨进程传递

JS File 对象创建

通过 WebKit JavaScriptCore 在页面中创建 File 对象

合成 DropEvent

构造 DataTransfer 和 DropEvent，dispatch 到页面的 drop 目标元素

构建系统

ZhiStar Nova 使用纯 C11 编写，通过 pkg-config 自动发现依赖， 提供简洁的 Makefile 构建系统。

编译要求

依赖说明
GCCC11 编译器
pkg-config自动发现 GTK/WebKit 依赖
WebKit2GTK 4.1浏览器引擎
GTK+ 3.0图形界面工具包
GLib 2.0基础库
libsoup 3.0HTTP 客户端库

构建命令

命令说明
make编译项目（带 -g 调试信息）
make clean清理编译产物
make run编译并运行
 
# Makefile 核心片段
CC = gcc
CFLAGS = -std=c11 -g -Wall $(shell pkg-config --cflags webkit2gtk-4.1 gtk+-3.0 glib-2.0 libsoup-3.0)
LDFLAGS = $(shell pkg-config --libs webkit2gtk-4.1 gtk+-3.0 glib-2.0 libsoup-3.0)

all: zhistar-nova

zhistar-nova: $(OBJS)
	$(CC) -o $@ $^ $(LDFLAGS)

clean:
	rm -f zhistar-nova $(OBJS)

run: all
	./zhistar-nova

崩溃处理

内建 Crash Handler，捕获 SIGSEGV 和 SIGABRT 信号， 输出 30 帧调用栈回溯，便于调试和问题定位。

调试提示

使用 -g 编译选项可生成调试符号。崩溃时会自动输出 backtrace， 配合 addr2line 可精确定位源码行号。
